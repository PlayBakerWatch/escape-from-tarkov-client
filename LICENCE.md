## 🧩 About

**Escape from Tarkov Client** is a comprehensive client mod for Escape from Tarkov featuring overlay, loot tracker, raid timer, stash manager, and custom scripts.

Based on popular tools like **EFT Overlay**, **Tarkov Tracker**, and **Stash Manager**.

## ✨ Features

### 🎮 Core Enhancements
- Overlay — in-game information display
- Loot Tracker — track valuable items and loot
- Raid Timer — monitor raid time and events
- Stash Manager — organize and manage inventory

### 🎨 Visual & UI
- Custom HUD — configurable on-screen elements
- Item Highlighter — highlight important items
- Map Overlay — display maps and extracts

### 🏋️ Utility & Automation
- Auto-Sell — automatically sell junk items
- Quick Buy — fast purchasing from traders
- Quest Helper — track quest objectives
- Script Support — run custom Lua scripts
